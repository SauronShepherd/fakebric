## Alcance

Se añadió `fakebric.query` como frontera separable de servicio: contratos de request/response 1.0, planner con nodos scan/filter/join/aggregate/project, ejecución agrupada sobre el DAX N1/N2 existente, adapter de resultados, paginación/límite de filas, cancelación/timeout cooperativos, cache LRU y métricas. El endpoint mínimo requerido `POST /api/v1/models/{id}/query` está expuesto en el router semántico.

El adapter DuckDB/Arrow no acepta SQL de usuario; únicamente materializa resultados ya evaluados mediante una tabla Arrow registrada en una conexión DuckDB en memoria. Si las dependencias no están presentes o el adapter falla, el backend Python conserva el resultado y añade un warning explícito.

## Caché

La clave incluye modelo, revisión, consulta y contexto de filtros, dataRevision, payload de datos y usuario. `page`, `pageSize` y timeout no forman parte de la ejecución materializada para permitir paginación estable. Una revisión nueva o un usuario diferente produce miss.
